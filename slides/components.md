@eyebrow: Component · math
# Math is just LaTeX
@kicker: `$…$` inline, `$$…$$` display — KaTeX is vendored in `slides/vendor`, so the deck still works offline

$$ x = v + a\,\varepsilon_1 + b\,\varepsilon_2 + c\,\varepsilon_1\varepsilon_2, \qquad \varepsilon_1^2 = \varepsilon_2^2 = 0 $$

$$ f(x) = f(v) + f'(v)\,a\,\varepsilon_1 + f'(v)\,b\,\varepsilon_2 + \bigl(f''(v)\,ab + f'(v)\,c\bigr)\,\varepsilon_1\varepsilon_2 $$

$$ H_{ij} = \frac{\partial^2 f}{\partial x_i\,\partial x_j} \qquad\Rightarrow\qquad \frac{k(k+1)}{2}\ \text{evaluations for $k$ chunks} $$

The $\varepsilon_1\varepsilon_2$ coefficient **is** the Hessian entry — inline math like $\varepsilon_1^2 = 0$ sits in running text, no nesting, no remainder.

# Code with automatic highlighting
@kicker: Fenced `julia` blocks are tokenized by the build script — end a line with `#!hl` to spotlight it

```julia title="Dense Hessian, zero allocations per call" sub="julia · HyperHessians.jl"
using HyperHessians, LinearAlgebra

rosenbrock(x) = sum(100(x[i+1] - x[i]^2)^2 + (1 - x[i])^2 for i in 1:length(x)-1)

x   = randn(256)
H   = similar(x, 256, 256)
cfg = HessianConfig(x)          # seeds + buffers, allocated once

hessian!(H, rosenbrock, x, cfg)  # 0 bytes allocated #!hl
```
@pills: good:0 B / call | good:528 evals, not 1024 | chunk 8 default

# Diff panels: red out, blue in
@kicker: A fenced `diff` block — `-`/`+` lines color themselves, pills carry the before/after numbers

```diff title="The two-line ForwardDiff patch" sub="ForwardDiff/src/dual.jl"
-function dual_definition_retval(::Val{T}, val::Real, deriv::Real, partial::Partials) where {T}
+@inline function dual_definition_retval(::Val{T}, val::Real, deriv::Real, partial::Partials) where {T}
     return Dual{T}(val, deriv * partial)
 end
-function dual_definition_retval(::Val{T}, val::Real, deriv1::Real, partial1::Partials,
-                                deriv2::Real, partial2::Partials) where {T}
+@inline function dual_definition_retval(::Val{T}, val::Real, deriv1::Real, partial1::Partials,
+                                deriv2::Real, partial2::Partials) where {T}
     return Dual{T}(val, _mul_partials(partial1, partial2, deriv1, deriv2))
 end
```
@pills: good:mul: 65.4 → 22.7 ns | good:ackley Hessian: 28.3 → 20.4 ms | good:rosenbrock: 41.2 → 23.9 ms
